# Mercedes-Benz 3D Logo Renderer

A C++/OpenGL application that renders an interactive 3D Mercedes-Benz logo with keyboard controls.

## Features

- 3D Mercedes-Benz logo rendering
- Interactive rotation using keyboard controls
- Realistic metallic colors
- "MERCEDES-BENZ" text display
- Smooth 3D perspective

## Controls

| Key | Action |
|-----|--------|
| W | Rotate Up |
| S | Rotate Down |
| A | Rotate Left |
| D | Rotate Right |
| ESC | Exit Program |

## Technologies

- C++
- OpenGL
- GLUT
